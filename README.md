## 👨‍💻 About

This repository contains the personal portfolio of **Sriram G S**, a B.Tech Information Technology student at **Karpagam College of Engineering, Coimbatore**.

The portfolio brings together academic background, technical skills, projects, coding profiles, work experience, certifications, achievements, and professional links in a single responsive web experience.

🔗 **Live:** [https://gssriram.live](https://gssriram.live)

### Core

| Technology | Usage |
|---|---|
| 🟧 **HTML5** | Semantic page structure and portfolio content |
| 🟦 **CSS3** | Styling, responsive layout, custom properties and visual design |
| 🟨 **JavaScript** | Navigation, dynamic content, interactions and theming |
| 🌐 **Tailwind CSS** | Utility-based styling through the compiled Tailwind CSS build |
| 🐙 **GitHub** | Version control and repository hosting |
| ⚙️ **GitHub Actions** | Automated coding-statistics synchronization |

### Development Approach

- Static website
- No frontend framework
- No application build pipeline required for the portfolio page
- HTML, CSS and JavaScript are maintained within the static site
- Deployed directly through GitHub Pages
